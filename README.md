# The Eye Of Sauron 🎻

Telegram-парсер для автоматизации учёта присутствия музыкантов оркестра.

Проект анализирует Telegram-опросы о репетициях и концертах,
сопоставляет пользователей с базой музыкантов в Google Sheets и
формирует готовый отчёт по составу.

------------------------------------------------------------------------

# Возможности

## Основной модуль `main.py`

Скрипт умеет:

-   подключаться к Telegram через Telethon;
-   работать с форумными темами Telegram;
-   искать нужную тему;
-   находить последний подходящий опрос;
-   определять пользователей, которые подтвердили участие;
-   поддерживать разные форматы опросов:
    -   репетиции: `✅ / ❌`;
    -   концерты: `Смогу... / Не смогу`;
-   учитывать несколько положительных вариантов ответа;
-   использовать пользовательские ключевые слова подтверждения;
-   получать инструменты музыкантов из Google Sheets;
-   считать состав оркестра;
-   считать количество необходимых пультов;
-   отправлять отчёт в Telegram "Избранное";
-   дополнительно отправлять отчёт в исходный чат.

------------------------------------------------------------------------

# База музыкантов

В качестве базы используется Google Sheets.

Структура таблицы:

  user_id   first_name   last_name   username   Инструмент   Обновлено
  --------- ------------ ----------- ---------- ------------ -----------

## Правила синхронизации

`get_id.py`:

-   получает участников Telegram-чата;
-   обновляет имя, фамилию и username;
-   добавляет новых пользователей;
-   сохраняет существующий инструмент;
-   обновляет дату синхронизации.

Инструмент никогда не изменяется автоматически.

# Конфигурация

Файл:

    config.ini

не должен храниться в GitHub.

Используйте шаблон:

    config.example.ini

Пример:

``` ini
[telegram]

api_id = YOUR_API_ID
api_hash = YOUR_API_HASH
session_name = orchestra_parser

chat_id = YOUR_CHAT_ID
default_topic_id = 0


[google_sheets]

credentials_file = credentials/google_service_account.json
spreadsheet_id = YOUR_SPREADSHEET_ID
worksheet_name = Musicians


[search]

search_limit = 300
votes_page_size = 100
```

# Аргументы `main.py`

Полная справка:

``` bash
python main.py --help
```

------------------------------------------------------------------------

## `--config`

Путь к файлу конфигурации.

По умолчанию:

``` bash
config.ini
```

Пример:

``` bash
python main.py --config my_config.ini
```

------------------------------------------------------------------------

## `--list-topics`

Показать список тем Telegram-чата и завершить работу.

Пример:

``` bash
python main.py --list-topics
```

Используется для поиска правильного `topic-id`.

------------------------------------------------------------------------

## `--topic-id`

Использовать конкретную тему.

Пример:

``` bash
python main.py --topic-id 4
```

Особенности:

-   `0` --- поиск по всему чату;
-   если не указан, используется стандартная логика выбора.

------------------------------------------------------------------------

## `--topic`

Поиск темы по части названия.

Пример:

``` bash
python main.py --topic репетиция
```

Скрипт найдёт подходящую тему форума.

------------------------------------------------------------------------

## `--poll`

Поиск опроса по части текста вопроса.

Пример:

``` bash
python main.py --poll концерт
```

Можно использовать для выбора конкретного опроса.

------------------------------------------------------------------------

## `--smart-sort`

Умная сортировка вариантов ответа "Смогу...".

Используется для концертных опросов.

Пример:

``` bash
python main.py --smart-sort
```

Позволяет корректнее выбирать варианты:

    Смогу к 10
    Смогу в 13:00
    Смогу к концерту

------------------------------------------------------------------------

## `--chat`

Переопределяет чат из `config.ini`.

Поддерживает:

-   ID;
-   username;
-   ссылку.

Примеры:

``` bash
python main.py --chat -1001234567890
```

``` bash
python main.py --chat @orchestra_chat
```

------------------------------------------------------------------------

## `--pick-chat`

Интерактивный выбор чата из списка диалогов.

Пример:

``` bash
python main.py --pick-chat
```

Используется, если неизвестен `chat_id`.

------------------------------------------------------------------------

## `--pick-chat-limit`

Количество диалогов для выбора.

По умолчанию:

    30

Пример:

``` bash
python main.py --pick-chat --pick-chat-limit 100
```

------------------------------------------------------------------------

## `--send-to-chat`

Дополнительно отправить отчёт в исходный чат ответом на сообщение
опроса.

Пример:

``` bash
python main.py --send-to-chat
```

Без этого флага отчёт отправляется только в "Избранное".

------------------------------------------------------------------------

## `--yes`

Добавляет пользовательские ключевые слова положительного ответа.

Можно использовать несколько раз.

Примеры:

``` bash
python main.py --yes "смогу"
```

Несколько:

``` bash
python main.py --yes "смогу" --yes "приду"
```

Через запятую:

``` bash
python main.py --yes "смогу,приду,✅"
```

Используется для нестандартных опросов.

# `get_id.py`

Запуск:

``` bash
python get_id.py
```

Назначение:

-   получить всех участников Telegram-чата;
-   синхронизировать Google Sheets.

После запуска:

-   новые участники появляются в таблице;
-   существующие обновляют Telegram-данные;
-   инструмент сохраняется.

------------------------------------------------------------------------

# Подсчёт пультов

## Струнные

Скрипки, альты и виолончели:

    1 пульт = 2 человека

Пример:

    5 скрипачей = 3 пульта

Используется округление вверх.

------------------------------------------------------------------------

## Остальные инструменты

Каждый музыкант получает отдельный пульт.

Пример:

    3 флейты = 3 пульта

Учитываются:

-   духовые;
-   медные;
-   перкуссия;
-   дирижёр;
-   остальные инструменты.

# Возможные ошибки

## Google Sheets не подключается

Проверить:

-   существует ли `google_service_account.json`;
-   таблица расшарена на `client_email`;
-   правильный `spreadsheet_id`.

------------------------------------------------------------------------

## Telegram не подключается

Проверить:

-   `API_ID`;
-   `API_HASH`;
-   файл сессии;
-   доступ к Telegram.
