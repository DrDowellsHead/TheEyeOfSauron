# The Eye of Sauron (Telegram Orchestra Parser)

Скрипт находит опрос в выбранном чате (и при необходимости — в теме форума), собирает **список проголосовавших** за “позитивные” варианты и отправляет статистику по инструментам в **Избранное**.

Поддерживает:
- Репетиции: варианты с `✅` / `приду` (и т.п.)
- Концерты/опросы с несколькими “позитивными” вариантами: объединяет участников по всем подходящим вариантам
- Умную сортировку “Смогу … / Могу …” по времени/смыслу (`--smart-sort`)
- Выбор чата интерактивно (`--pick-chat`)

> Важно: Telegram отдаёт список проголосовавших только для **неанонимных** опросов (public voters).  
> Если опрос анонимный — получить `user_id` голосовавших нельзя.

## Конфиг (секреты не хранятся в коде)

Создай файл `config.ini` (он **не должен коммититься**). В репозитории держи только `config.example.ini`.

### config.example.ini (пример)

```ini
[telegram]
api_id = 123456
api_hash = put_hash_here
session_name = orchestra_parser

chat_id = -1002291481872
default_topic_id = 4

[files]
musicians_csv = Музыканты.csv

[search]
search_limit = 300
votes_page_size = 100
```

## Флаги командной строки

### `--config <path>`
Путь к конфигу (по умолчанию `config.ini`).

```bash
python -m eye --config config.ini
```

### `--list-topics`
Показать темы форума (topic) в текущем чате и выйти.

```bash
python -m eye --list-topics
```

### `--chat <ref>`
Выбрать чат явно: `id`, `@username`, ссылка. Перезаписывает `chat_id` из `config.ini`.

```bash
python -m eye --chat -1002291481872
python -m eye --chat @your_supergroup
```

### `--pick-chat`
Интерактивно выбрать чат из списка диалогов.

```bash
python -m eye --pick-chat
```

### `--pick-chat-limit <N>`
Сколько диалогов показать при `--pick-chat` (по умолчанию 30).

```bash
python -m eye --pick-chat --pick-chat-limit 80
```

### `--topic-id <id>`
Задать `topic_id` (ID темы форума), в которой искать опрос.

```bash
python -m eye --topic-id 4
```

### `--topic "<часть названия>"`
Найти тему по части названия (если совпадений несколько — предложит выбрать).

```bash
python -m eye --topic "концерт"
```

### `--poll "<подстрока>"`
Найти опрос по подстроке в вопросе.  
Если найдено несколько — предложит выбрать. Если ничего — возьмёт самый последний опрос в теме/чате.

```bash
python -m eye --poll "Бал в Атриуме"
```

### `--smart-sort`
Умная сортировка позитивных вариантов (полезно, когда много “Смогу … / Могу …”):
- сначала варианты с распознанным временем (`к 10`, `в 13:00`…) по возрастанию
- затем без времени по смыслу: чек/саундчек → репетиция → концерт → прочее

```bash
python -m eye --smart-sort
```

### `--send-to-chat`
Дополнительно отправить отчёт в чат ответом на сообщение опроса (помимо Избранного).

```bash
python -m eye --send-to-chat
```

## Флаг `--yes` (ключевые слова для “позитивных” ответов)

По умолчанию скрипт пытается сам распознавать “позитивные” варианты (например `✅`, `приду`, `смогу`, `буду` — зависит от вашей версии/настроек).

Флаг `--yes` позволяет **явно задать**, какие варианты считать “позитивными”:
- можно указывать **несколько раз**
- можно перечислять **через запятую**
- поиск идёт как **подстрока** (без учёта регистра)
- отрицательные варианты вида `Не ...` автоматически отсекаются (например `Не смогу` не попадёт)

Примеры:

**1) Считать позитивными только варианты со словом “смогу”:**
```bash
python -m eye --yes "смогу"
```

**2) Считать позитивными варианты со словом “могу” (как в опросах “Могу 02.06 …”):**
```bash
python -m eye --yes "могу"
```

**3) Несколько ключей повторением флага:**
```bash
python -m eye --yes "✅" --yes "приду" --yes "смогу"
```

**4) Несколько ключей одной строкой через запятую:**
```bash
python -m eye --yes "✅,приду,смогу"
```

## Типовые проблемы

### `Опрос анонимный — Telegram не отдаёт список проголосовавших`
Опрос должен быть **неанонимным**.

### `POLL_VOTE_REQUIRED`
Иногда Telegram требует, чтобы аккаунт, которым ты запускаешь скрипт, **сам проголосовал** в опросе.
Проголосуй любым вариантом и запусти снова.

### Termux: нет доступа к Downloads
Сделай один раз:

```bash
termux-setup-storage
```
